# Fotos reales pendientes · Ford Mustang GT 2018

Esta carpeta es el destino de las imágenes del lote demo `Ford Mustang GT`, año 2018. El color de carrocería no está registrado en el inventario actual: antes de añadir las fotos, elegí/confirmá el color real de la unidad y usá la misma unidad y el mismo color de pintura en todas las tomas exteriores. No mezcles fotos de catálogos, años, generaciones, versiones GT ni autos distintos.

Colocá aquí cinco archivos JPG diferentes (idealmente 1200 × 800 píxeles o más), con estos nombres y tomas:

1. `01-front-left.jpg`: vista exterior tres cuartos frontal izquierda.
2. `02-left-side.jpg`: perfil lateral izquierdo completo.
3. `03-front-right.jpg`: vista exterior tres cuartos frontal derecha.
4. `04-rear.jpg`: parte trasera completa.
5. `05-interior.jpg`: tablero e interior de esa misma unidad.

Las cuatro tomas exteriores deben permitir verificar que se trata del mismo Mustang GT 2018 y conservar el color de pintura. La quinta debe ser el interior del mismo auto. Evitá marcas de agua o imágenes sin permiso de uso. Al agregar las fotos, ejecutá `npm run build` para copiarlas a `dist` y volvé a abrir el carrusel.
